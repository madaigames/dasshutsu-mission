# 脱出×妨害mission

研究所を舞台にした、脱出と防衛のブラウザーゲーム試作版です。

## 遊び方

`index.html` をブラウザーで開き、「NPCと対戦する」を選んでください。

- 10×10の研究所で、スタート（右下）から出口（左上）までの迷宮を作ります。
- 防衛フェーズは実時間180秒です。仕掛けを選び、盤面の床をクリックして配置します。
- 最短脱出ルートが58秒を超える配置はできません。鍵付き扉を通るルートでは、鍵入り宝箱への立ち寄り時間も計算します。宝箱へ到達できない配置はできません。スタートと出口は設置できません。罠は外周にも設置できます。
- 「これで完成」を押した後、相手側の防衛フィールドが完成してから攻略フェーズへ進みます。NPC戦ではNPCも防衛フェーズ中に毎回ランダムなフィールドを作ります。矢印キーか隣接マスのクリックで移動してください。通過したマスには行動順の番号が付き、得点計算画面にもルートを表示します。
- 博士が置ける壁は電気壁、エイリアンが置ける壁は粘膜壁です。壁は通過できません。
- 罠、敵、落とし穴、鍵、扉の攻略にかかる秒数は攻略タイマーに加算されます。
- 防衛マップ制作と攻略の前に説明画面を表示します。NPC戦ではプレイヤーがSTARTを押すと進み、ふたりで遊ぶ場合は博士・エイリアン双方のSTART確認後に進む設計です。オンライン同期は未接続のため、対人戦での相手START通知には通信接続が必要です。
- NPC戦ではプレイヤーの攻略後にNPCもプレイヤーの防衛マップを攻略します。NPCは仕掛けを多めに設置します。攻略ではマップ難易度に応じて時間切れ率を補正し、クリア時は60秒45%、59秒30%、58秒以内25%の割合で結果を決めます。
- 対戦後は勝敗表示の前に博士・エイリアン別の得点計算を表示します。攻略点、速さボーナス（速い側に＋1）、防衛成功点を個別に確認できます。

## 仕掛け

| 仕掛け | 効果 |
| --- | --- |
| 壁 | 通過不可。博士専用の黄色い電気壁、エイリアン専用の緑色の粘膜壁 |
| 罠 | 博士は金属製トラバサミ、エイリアンはベトベトした粘膜罠。解除に3秒 |
| 敵 | 博士は警備ロボット、エイリアンは赤いスライム分体。討伐に5秒 |
| 落とし穴 | 橋をかけるのに5秒 |
| 鍵入り宝箱 | 扉1つにつき宝箱1つ。博士用の茶色い鍵／エイリアン用の緑の鍵が入る。探索に3秒 |
| 扉 | 博士は鍵付きシャッター、エイリアンは固めた粘膜扉。対応する鍵を1つ消費して開ける |

## GitHub Pages で公開する

このフォルダーをGitHubリポジトリに追加し、Pagesの公開元を `main` ブランチ / `/(root)` に設定すると公開できます。ビルドや依存パッケージは不要です。

## 試作版の範囲

部屋コード表示とコピー操作は画面デモです。オンライン同期、招待参加、同時の役割選択は未接続です。NPC対戦はローカルで遊ぶためのプロトタイプです。NPCは一手ずつ移動するのではなく、マップ難易度に応じた確率シミュレーションで攻略結果を判定します。

## サウンドと設定

表紙・説明画面・防衛フェーズ、攻略フェーズ、得点計算・エンディングで場面別のBGMを再生します（全曲共通の初期音量15%）。右上の歯車から全曲の音量と攻略フェーズのルートハイライトを切り替えられます。

## キャラクター画像

`assets/doctor.png` は博士、`assets/alien.png` はエイリアンです。選択画面と勝敗エンディングでは博士が左、エイリアンが右に表示されます。

- 博士の鍵付きシャッターは、鍵を持たずに触れても閉じたままで通過できません。鍵を持って踏むと開いた状態になり、その後は鍵なしでも通過できます。

エイリアンの鍵付き粘膜扉も、鍵を持って踏むと開いた画像に切り替わり、以後は鍵なしで通過できます。

壁画像はエイリアンの粘膜壁が左側の見本（`assets/mucus-wall.png`）、博士の電気壁が右側の見本（`assets/electric-wall.png`）です。盤面と設置ツールに反映しています。

- 宝箱は博士・エイリアン共通の画像で、通過前は閉じた画像、通過後は開いた画像です。鍵は宝箱ごとに1個獲得し、攻略画面の所持品欄に「鍵1つ」「鍵2つ」のように所持数を表示します。扉を1つ開けるたびに鍵を1個消費します。宝箱・扉は最大4セットです。
- 博士マップの宝箱は茶色のシャッター用鍵、エイリアンマップの宝箱は緑色の粘膜扉用鍵を入れます。
- 壁、罠、敵、扉、宝箱、鍵の絵文字を添付画像に置き換えています。

盤面の背景には添付の見本画像（`assets/field-board.png`）を使い、操作用の10×10マスを重ねています。
